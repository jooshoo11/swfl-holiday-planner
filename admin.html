⚙️ GitHub Auto-Publisher Configuration

This dashboard connects directly to your GitHub repository (jooshoo11/swfl-holiday-planner) so that when you approve or edit an event, it commits the changes automatically.

🔑 Quick 1-Minute Token Setup:

  1. Go to GitHub Settings → Personal Access Tokens (Classic).
  2. Set Note: SWFL Holiday Planner Auto-Publisher.
  3. Select the repo check-box (Full control of private and public repositories).
  4. Click Generate token at the bottom and copy your token (it starts with ghp_).
  5. Paste your token below. It is stored securely only inside your personal browser storage.
